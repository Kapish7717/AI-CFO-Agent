3. LOGGING PIPELINES & TABLES
--------------------------------------------------------------------------------

A. DATABASE CHAT MESSAGES LOGGING:
   - Target Table: `user_chat_messages`
   - Schema:
     * id: Serial identifier (PK)
     * user_id: ID of the user (FK referencing users.id)
     * sender: Source of message ('user' or 'agent')
     * message_text: Raw string body of the chat prompt/response
     * timestamp: Time of entry insertion (Default CURRENT_TIMESTAMP)
   - Read Workflow: Handled when client hits GET `/api/chat/history?user_id=<id>`.
     Queries messages sequentially ordered by timestamp ascending.

B. SYSTEM RUNTIME LOGGING:
   - Configured using python-standard logging in `api.py`.
   - Handler 1 (Console): Stdout stream handler prints requests and tool runs.
   - Handler 2 (File): `cfo_backend.log` file captures warnings, DB errors, 
     Google OAuth exchanges, and stack traces dynamically.

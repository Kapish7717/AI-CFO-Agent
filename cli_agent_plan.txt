================================================================================
                    AI CFO AGENT - CLI CONVERSION PLAN & SPECIFICATION
================================================================================

This document details the plan to build a Command Line Interface (CLI) version
of the AI CFO Agent, reusing the existing LangGraph orchestrator and database.

--------------------------------------------------------------------------------
1. ARCHITECTURE ADVANTAGES & REUSE
--------------------------------------------------------------------------------
By using a modular architecture, we can easily create a CLI entry point:
- **Reuse Agent**: We can import the compiled `graph` from `agent.py` directly.
- **Reuse Tools**: The agent will still spawn `mcp_client.py` as an stdio MCP
  sub-process to execute all financial analysis and email/calendar tools.
- **Reuse DB**: We can query and write chat history/settings to SQLite via `database.py`.

--------------------------------------------------------------------------------
2. PROPOSED COMMAND LINE OPTIONS
--------------------------------------------------------------------------------
A CLI tool named `cfo_cli.py` will support two modes:
A. **One-Off Command Mode**: Pass files, budgets, and prompts directly.
B. **Interactive Chat Mode**: Start a persistent terminal session (REPL).

Syntax options:
  -p, --prompt TEXT            The instruction to send to the CFO agent.
  -u, --user-id INTEGER        User ID context (default: 2).
  -e, --expense PATH           Path to the expense CSV to upload and register.
  -r, --revenue PATH           Path to the revenue CSV to upload and register.
  --budget-marketing FLOAT     Custom marketing budget limit.
  --budget-operations FLOAT    Custom operations budget limit.
  --budget-travel FLOAT        Custom travel budget limit.
  -i, --interactive            Run in interactive shell/REPL mode.

--------------------------------------------------------------------------------
3. DETAILED IMPLEMENTATION STEPS
--------------------------------------------------------------------------------

STEP 1: SETUP DEPENDENCIES
- Use standard library `argparse` or install `click` / `typer` for CLI parsing.
- (Optional) Install `rich` to print beautiful progress bars, markdown tables,
  and colorized agent thought streaming in the terminal.

STEP 2: CREATE CLI ENTRYPOINT (`cfo_cli.py`)
Create a new file `cfo_cli.py` in the root workspace. Outline structure:

```python
import asyncio
import argparse
import sys
import os
import shutil
from agent import graph
from db.database import update_user_settings, save_user_chat_message, get_user_chat_history

# Helper to copy and update local files to "uploads" directory
def prepare_files(user_id, expense_path, revenue_path):
    updates = {}
    os.makedirs("uploads", exist_ok=True)
    if expense_path and os.path.exists(expense_path):
        dest = f"uploads/{user_id}_{os.path.basename(expense_path)}"
        shutil.copy(expense_path, dest)
        updates["expense_file_path"] = os.path.abspath(dest).replace("\\", "/")
        updates["expense_file_name"] = os.path.basename(expense_path)
    if revenue_path and os.path.exists(revenue_path):
        dest = f"uploads/{user_id}_{os.path.basename(revenue_path)}"
        shutil.copy(revenue_path, dest)
        updates["revenue_file_path"] = os.path.abspath(dest).replace("\\", "/")
        updates["revenue_file_name"] = os.path.basename(revenue_path)
    
    if updates:
        update_user_settings(user_id, updates)
    return updates

async def run_agent_stream(user_id, prompt):
    # Prefix user_id context so the agent passes it to tools
    full_prompt = f"USER_ID: {user_id}\n\n{prompt}"
    save_user_chat_message(user_id, "user", prompt)
    
    initial_state = {"messages": [("user", full_prompt)]}
    bot_response = ""
    
    print("\n[AI CFO] Initiating workflow...")
    async for s in graph.astream(initial_state, stream_mode="updates"):
        step_name = list(s.keys())[0]
        final_message = ""
        if "messages" in s[step_name] and s[step_name]["messages"]:
            final_message = s[step_name]["messages"][-1].content
            
        if step_name == "agent" and final_message:
            bot_response = final_message
            # Print word-by-word streaming in console
            print(f"\r[Agent Thinking]: {bot_response}")
        elif step_name == "tools":
            print(f" -> Step completed: {final_message}")
            
    if bot_response:
        save_user_chat_message(user_id, "agent", bot_response)
    print("\n[AI CFO] Done.")

```
